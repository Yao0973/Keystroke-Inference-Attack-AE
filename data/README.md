# Data Directory

The artifact data are now physically organized here:

- `classification/`: single-keystroke train/test feature datasets
- `pin_reconstruction/`: multi-digit PIN train/test datasets
- `robustness/hand_size/`: hand-size and posture robustness datasets
- `robustness/battery_background/`: battery/background-load robustness datasets
- `raw_signals/`: raw traces used by legacy signal-processing scripts
- `derived/`: derived intermediate data produced by legacy preprocessing

See `docs/repository_inventory.md` for the detailed inventory.
