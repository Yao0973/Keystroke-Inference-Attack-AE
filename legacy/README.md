# Legacy Scripts

This directory preserves the original research scripts after cleanup of the repository root.

Subdirectories:

- `processing/`: signal preprocessing and feature extraction
- `training/`: model training and analysis scripts
- `inference/`: PIN inference and attack evaluation scripts
- `robustness/`: robustness and perturbation analysis scripts
- `visualization/`: standalone visualization/evaluation scripts
- `orchestration/`: legacy orchestration helpers

These files are kept primarily for provenance and author use. The supported AEC interface is the new wrapper layer in `scripts/` and `src/keystroke_artifact/`.
